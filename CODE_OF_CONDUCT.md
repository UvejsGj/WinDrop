# Code of conduct

WinDrop adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct. Everyone taking part in issues, pull requests and discussions here
is expected to follow it.

In short: be respectful and constructive, assume good faith, and criticise work rather than
people. This is a learning project, so questions at every level are welcome. Harassment,
personal attacks, and publishing anyone's private information are not.

## Reporting

Report conduct problems to the maintainer, [@UvejsGj](https://github.com/UvejsGj). If a
report needs privacy, open an issue saying only that, with no details, and a private
channel will be arranged.

## Enforcement

The maintainer may edit, hide or remove comments, issues, commits and other contributions
that break this code, and may block anyone who does so repeatedly or seriously.
